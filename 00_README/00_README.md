## Tips

- Start a **new chat per file** so the model has full context for that subject.
- Every question is tagged **[Must-know SDE-1]** or **[Stretch]**. When short on time, skip [Stretch].
- Do DSA **every day**, even while working through other files.
- Use **22** weekly to test yourself on completed subjects.
- Verify AI-generated problem lists and "most asked" claims against LeetCode company tags, NeetCode 150, or the Striver SDE Sheet.
- If your resume changes, update the "Candidate Profile" section in [_header.md](../_header.md), then run `.\build_prompts.ps1` in PowerShell (it re-applies the header to every file).
