1. Controller receives the request

The API endpoint receives a TransactionRequest containing an account ID and amount. The controller delegates the operation to the service; it does not calculate the new balance itself.

Connect the dots: Controller receives → Service coordinates and starts a transaction → Repository finds and locks the row → `BankAccount` enforces the balance rule → transaction commits (or rolls back on error).
